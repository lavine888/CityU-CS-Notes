## 主要内容

- 数据工程生命周期：采集、存储、处理、治理、服务
- 数据建模：关系模型、维度建模、数据仓库 vs 数据湖
- ETL / ELT 管道设计与调度
- 大数据技术栈：分布式文件系统、批处理、流处理基础
- 数据质量、数据血缘与元数据管理
- SQL/NoSQL 数据库选型与实践
