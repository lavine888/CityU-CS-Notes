## 主要内容

- 商业数据分析流程：问题定义、数据准备、建模、评估、部署
- 描述性分析：汇总统计、可视化、仪表盘
- 预测性分析：回归、分类、聚类基础
- 关联规则、推荐系统与文本分析入门
- A/B 测试、因果推断商业应用
- 数据驱动的商业决策与案例研究
