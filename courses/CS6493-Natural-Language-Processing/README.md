# CS6493 Natural Language Processing

> 香港城市大学 CS 硕士 · Semester B 2025/26

- **课程代码**：CS6493
- **课程名称**：Natural Language Processing
- **学分**：3
- **状态**：🟡 已有课程材料

## 主要内容

- 文本预处理：分词、词性标注、停用词、词干提取
- 语言模型：n-gram、平滑、困惑度
- 词向量：Word2Vec、GloVe、语义相似度
- 序列标注：命名实体识别（NER）、隐马尔可夫模型
- 句法分析、依存解析基础
- Transformer 架构与大语言模型入门
