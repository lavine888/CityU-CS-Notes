# CS5285 Information Security for eCommerce

> 香港城市大学 CS 硕士 · Semester A 2025/26

- **课程代码**：CS5285
- **课程名称**：Information Security for eCommerce
- **学分**：3
- **状态**：🟡 已有课程材料

## 主要内容

- 信息安全基础：CIA 三元组、威胁模型、攻击类型
- 密码学：对称/非对称加密、哈希、数字签名
- 公钥基础设施（PKI）与证书体系
- Web 安全：SSL/TLS、HTTPS、常见 Web 攻击与防御
- 电子商务支付安全、身份认证与访问控制
- 安全协议与安全工程实践
