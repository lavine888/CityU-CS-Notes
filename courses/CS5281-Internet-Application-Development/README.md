# CS5281 Internet Application Development

> 香港城市大学 CS 硕士 · Semester B 2025/26

- **课程代码**：CS5281
- **课程名称**：Internet Application Development
- **学分**：3
- **状态**：🟡 已有课程材料

## 主要内容

- Web 应用基础：HTTP/HTTPS、客户端-服务器架构、浏览器渲染
- 前端开发：HTML/CSS/JavaScript、响应式设计、主流框架基础
- 后端开发：服务器端语言、RESTful API 设计、路由、模板引擎
- 数据库集成：关系型数据库、ORM/ODM、会话管理
- Web 安全、认证授权、部署与运维基础
- 全栈项目实践
