# CS5187 Vision and Image

> 香港城市大学 CS 硕士 · Semester A 2025/26

- **课程代码**：CS5187
- **课程名称**：Vision and Image
- **学分**：3
- **状态**：⚪ 待整理

## 主要内容

- 数字图像基础：采样、量化、颜色空间、直方图
- 图像滤波与增强：卷积、平滑、锐化、边缘检测
- 特征提取：角点、SIFT/HOG、形态学处理
- 图像分割：阈值、聚类、轮廓、分水岭
- 计算机视觉任务：目标检测、图像分类、语义分割基础
- 深度学习与视觉：CNN 架构（AlexNet、ResNet 等）入门
