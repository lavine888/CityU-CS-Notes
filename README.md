## 这个仓库是做什么的

这是我在香港城市大学（CityU）攻读 MSc 计算机方向期间修过的课程笔记仓库。每一门课对应一个目录，里面按主题整理学习心得、重点梳理、易错点和参考资源。

**定位**：
- 🎓 **个人学习沉淀**：不是官方讲义，也不是标准答案，是我"学过一遍后的理解"。
- 📂 **按课归档**：以 CityU 课程代码命名目录，结构清晰，方便检索。
- 🤝 **开放共建**：欢迎同校/同方向的同学 PR 补充笔记、修正理解、补充参考。

> ⚠️ 版权说明：本仓库中的 `materials/official/` 目录收录了 CityU 课程门户可下载的学习资料（讲义、教程、作业等），旨在方便同学集中查阅。版权归原作者所有及 CityU 所有，本人不主张任何版权。若任课教师或版权方认为不妥，请通过 Issue 或邮件联系，将第一时间处理。仓库中的个人笔记与整理遵循 [MIT](LICENSE) 协议开放。

## 怎么用

1. 找到你想看的课程目录，点进去读 `README.md`。
2. 每门课的目录会按主题列出笔记（目前还在填充中）。
3. 想贡献？参考 [`CONTRIBUTING.md`](CONTRIBUTING.md) 和 [`templates/note-template.md`](templates/note-template.md)。
