## 这个仓库是做什么的

这是我在香港城市大学（CityU）攻读 MSc 计算机方向期间修过的课程笔记仓库。每门课对应一个目录，整理我的学习理解、重点梳理与易错点，也收录了期末周同学们在课程群里慷慨分享的学习资料。

**定位**：
- 📝 **个人学习沉淀**：基于我真实修过的课程，按主题整理学习心得、重点与易错点。
- 🌐 **社群资料汇总**：部分资料来源于 CityU 课程群等社群，特别感谢期末周主动分享笔记的同学们。
- 🤝 **开放共建**：欢迎同校/同方向的同学继续 PR 补充笔记、修正理解、补充参考。

> ⚠️ 版权说明：本仓库中的 `materials/official/` 目录收录了 CityU 课程门户可下载的学习资料（讲义、教程、作业等），旨在方便同学集中查阅。版权归原作者所有及 CityU 所有，本人不主张任何版权。若任课教师或版权方认为不妥，请通过 Issue 或邮件联系，将第一时间处理。仓库中的笔记基于我的课程学习整理，来源包括本人原创及从课程社群收集的同学分享；若任何原作者认为不妥，可随时通过 Issue 或邮件联系撤下。

## 怎么用

1. 找到你想看的课程目录，点进去读 `README.md`。
2. 每门课的目录会按主题列出笔记（目前还在填充中）。
3. 想贡献？参考 [`CONTRIBUTING.md`](CONTRIBUTING.md) 和 [`templates/note-template.md`](templates/note-template.md)。
